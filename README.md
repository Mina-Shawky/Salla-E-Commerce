<h2>📌 About The Project</h2>

<p>
  <strong>Salla</strong> is an E-Commerce RESTful API developed
  using ASP.NET Core Web API. The project aims to provide
  backend services for an online shopping application,
  following a clean and organized layered architecture.
</p>

<h2>🚀 Features</h2>

<ul>
  <li>User Authentication and Account Management</li>
  <li>Order Management</li>
  <li>Checkout Process</li>
  <li>Email Notifications using SMTP</li>
  <li>Generic Repository Pattern</li>
  <li>Generic Service Pattern</li>
  <li>DTO Mapping using Mapster</li>
  <li>Dependency Injection</li>
  <li>Reusable and Maintainable Code</li>
</ul>

<h2>🛠️ Technologies Used</h2>

<ul>
  <li>C#</li>
  <li>ASP.NET Core Web API</li>
  <li>Entity Framework Core (if configured)</li>
  <li>Mapster</li>
  <li>SMTP Email Service</li>
  <li>SQL Database (configure your database provider)</li>
</ul>

<h2>🏗️ Project Structure</h2>

Salla-E-Commerce

<h2>⚙️ Getting Started</h2>

<h3>Prerequisites</h3>

<ul>
  <li>.NET SDK</li>
  <li>Visual Studio</li>
  <li>Git</li>
  <li>Your configured database provider</li>
</ul>

<h3>Installation</h3>

<ol>
  <li>
    Clone the repository:
    <pre>git clone https://github.com/Mina-Shawky/Salla-E-Commerce.git</pre>
  </li>
  <li>
    Navigate to the project directory:
    <pre>cd Salla-E-Commerce</pre>
  </li>
  <li>
    Restore dependencies:
    <pre>dotnet restore Salla.slnx</pre>
  </li>
  <li>
    Configure your database connection string and email settings.
  </li>
  <li>
    Open <strong>Salla.slnx</strong> using Visual Studio.
  </li>
  <li>
    Set Salla as the startup project and run the application.
  </li>
</ol>
